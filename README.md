### Oi, eu sou o Pedro 👋

Cuido de growth e tráfego pago na **[BrainJuice](https://brainjuice.com.br)**. Por aqui ficam as ferramentas internas que a gente constrói para tocar a operação: medir anúncio, organizar teste e cuidar das avaliações dos clientes.

#### 🧰 Ferramentas internas

| Projeto | O que faz |
| --- | --- |
| [agenda-testes](https://github.com/figueiredoedf/agenda-testes) | Gerenciador dos testes de anúncios: quadro de testes, ranking de criativos, diário automático, relatórios e duplicação para a escala, direto pela API da Meta. |
| [brainjuice-reviews](https://github.com/figueiredoedf/brainjuice-reviews) | **Brainviews**, o sistema próprio de avaliações da loja, que substituiu o Judge.me: coleta, moderação, widget na Shopify, feed para o Google e alertas para o SAC. |

> Os repositórios são privados. Quem é do time e precisa de acesso, me chama.
